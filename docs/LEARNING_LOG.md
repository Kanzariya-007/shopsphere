# Learning Log

## Understood and Demonstrated
* **TypeScript Basics:** Strict syntactical superset of JavaScript providing static typing.
* **npx:** Node Package Execute for running npm packages without global installation.
* **Git Staging and Semantic Commits:** Version control workflow using conventional commit messages.
* **Next.js App Router:** Filesystem-based routing where `app/page.tsx` maps to the root URL `/`.
* **TSX and React Components:** Writing HTML-like markup inside TypeScript functions to build reusable UI elements.
* **Tailwind CSS Utility Classes:** Styling components directly via `className` without external CSS files.

## Not Covered Yet
* Database schema design
* Asynchronous server actions
* Dynamic routing
