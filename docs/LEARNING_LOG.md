# Learning Log

## Understood and Demonstrated
* **TypeScript Basics:** A strict syntactical superset of JavaScript that adds optional static typing, compiled down to JS via `tsc`.
* **npx:** Node Package Execute, a tool to run executable packages directly from the npm registry without global installation.
* **Git Staging:** The intermediate "loading dock" step (`git add`) required before committing files to version control.
* **Semantic Commits:** A standardized commit message format (`type(scope): message`) to ensure project history remains readable.

* React Server Components (Next.js App Router)
* Tailwind CSS utility classes

## Not Covered Yet
